# Experiment 4: Reading Data from Text Files, Excel, and the Web

## Aim

To read and process data from different sources such as **text/CSV files, Excel files, and web-based datasets** using Pandas.

## Objective

The objective of this experiment is to understand how data can be imported from multiple sources and prepared for further data analysis and visualization.

## Topics Covered

* Reading data from CSV/text files
* Reading data from Excel files
* Reading data from web sources
* Displaying imported datasets
* Handling missing values
* Forward-fill and backward-fill methods
* Removing missing records
* Saving processed datasets
* Data preprocessing using Pandas

## Data Sources Explored

### 1. Text/CSV Files

CSV files are read using Pandas and converted into DataFrames for analysis and processing.

### 2. Excel Files

Excel worksheets are imported using Pandas. Specific sheets can be selected for further processing.

### 3. Web Data

Datasets available through publicly accessible URLs are directly imported into Pandas DataFrames.

## Data Processing Operations

### Missing Value Handling

Missing values are handled using different techniques:

* **Forward Fill (`ffill`)** – fills missing values using the previous available value.
* **Backward Fill (`bfill`)** – fills missing values using the next available value.
* **Drop Missing Values (`dropna`)** – removes records containing missing values.

### Data Export

After processing, the datasets can be saved into new files for future analysis.

Supported output formats explored in this experiment include:

* CSV
* Excel

## Tools and Technologies

* Python 3.x
* Pandas
* Jupyter Notebook
* CSV/Text Files

* Web-based datasets

## Learning Outcomes

After completing this experiment, the learner will be able to:

* Import data from CSV/text files.
* Read data from Excel worksheets.
* Retrieve datasets from web URLs.
* Display and inspect imported data.
* Identify and handle missing values.
* Apply forward-fill and backward-fill techniques.
* Remove incomplete records when required.
* Save processed datasets into CSV and Excel formats.
* Understand the importance of data acquisition in data analytics.

## Result

Data was successfully read from **text/CSV files, Excel files, and web sources** using Pandas. Missing values were handled and processed datasets were saved for further analysis.

## Conclusion

This experiment demonstrates the ability of Pandas to acquire data from multiple sources and perform basic preprocessing. Reading data from different formats is an essential first step in the **Data Analytics and Visualization workflow**.
